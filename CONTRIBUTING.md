# Contributions

This project is a strictly solo development process. 

It serves as a personal architectural manifesto and a highly specific workspace tailored exactly to my preferences, workflows, and standards.

Because of the rigid and unconventional nature of the codebase—relying heavily on raw memory manipulation and extreme zero-allocation constraints—outside contributions introduce unnecessary friction.

Therefore, **I do not accept any Pull Requests, feature requests, or external contributions of any kind.**

Feel free to fork the code or use it as inspiration for your own zero-GC experiments, but this upstream repository will remain exclusively managed by its sole author.
